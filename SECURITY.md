| Version | Supported          |
| ------- | ------------------ |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **SwapLM**, please do NOT report it publicly on GitHub Issues.

Instead, please send an email directly to the project maintainers or report it privately through GitHub Security Advisory.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested remediations.

We will acknowledge receipt of your report within 48 hours and work with you to resolve the issue promptly before public disclosure.
